直接用瀏覽器（建議 Chrome／Edge）打開 `rpg_prototype.html`。所有圖片、CSS、JS 都內嵌在這一個檔案裡，可以離線玩。

## v3.6.1 更新：艾薇說話嘴型

- 艾薇站姿（日常、戰鬥、正式、睡衣、旅行，保守版與大膽版）接上說話嘴型，開語音時與莉娜一樣只動嘴、表情暫停。持握姿勢、瑪莎、托比不變。

## v3.6 更新：立繪動態

- **立繪會動了**（冒險畫面與私下空間）：輕微呼吸、頭部微動、髮絲與裙擺輕擺；持握武器的合成立繪也一起動（武器本身不會跟著髮絲／裙擺晃）。
- **眨眼與微表情**：自然眨眼（說話時也會眨）；沒說話時偶爾出現輕笑、挑眉、皺眉思考、視線移開、連眨、慢眨。只動眼睛、眉毛、嘴附近，不會整張臉替換。劇情裡的情緒（開心、驚訝、難過…）會觸發對應的微表情。
- **說話只動嘴**：開啟語音（TTS）時，莉娜與艾薇的嘴型照聲音大小開合（看得到牙齒的張嘴幅度），說話時表情暫停；說話前表情先收斂，說完隔約 0.4 秒才再開始。沒有開語音、只有文字時嘴巴不動（避免沒有聲音卻一直開合）。
- **誰有哪些效果**：
  - 莉娜：五套服裝的保守版與大膽版（站姿）＝呼吸＋眨眼＋微表情＋說話嘴型。
  - 艾薇：五套服裝的保守版與大膽版（站姿）＝呼吸＋眨眼＋微表情＋說話嘴型（與莉娜同一套說話／表情狀態機；日常裝嘴型對位到其他服裝）。
  - 持握武器／物品的姿勢圖、瑪莎、托比＝只有身體呼吸（瑪莎、托比也不做髮絲與臉部；原圖完全沒有修改）。
- **設定 → 遊戲 →「立繪動態」**：預設開啟，關閉後立刻回到原本的靜態立繪（說話時一樣是原本的上下起伏）。瀏覽器不支援 WebGL 時自動維持靜態。只畫看得到的立繪、依顯示大小算繪、分頁切走時暫停、最多每秒 30 格；較慢的裝置會自動降低格數（最低約每秒 12 格），不拖慢遊戲操作。
- **紙娃娃圖層（準備中）**：如果有拆好的圖層（後髮、身體服裝、臉、前髮），網頁版會在開啟動態時才另外下載，用來做更自然的髮絲擺動；目前已接上莉娜日常服（保守版與大膽版）的圖層；沒有圖層時用整張立繪。單一 HTML 離線版（file://）因瀏覽器安全限制不讀圖層，自動用整張立繪。

## v3.5.1 更新：魔物擴充

- **新增 18 種奇幻魔物**（只在「中世紀奇幻小鎮」世界觀出現，其他世界觀不會混入）：獸人掠奪者、座狼、梟熊、溺屍鬼、獅鷲、鷹身女妖、古墳屍妖、狗頭人、豺狼人、寶箱怪、巨蠍、雪原巨猿、巨鉗蟹、正午魅影、邪教徒、走私販，以及兩隻首領：**林境之主・萊希**、**遠古巨龍**。
- **補上 8 種原有魔物的立繪**：林鹿、蝙蝠群、行屍、食屍鬼、幽魂、幽光精、食人魔、石化蜥。現在奇幻世界觀的魔物遭遇卡與戰鬥畫面都有立繪。
- **依環境遭遇**（沿用原本的地形／時段／危險度規則，沒有改寫）：
  - 水邊（海岸、河岸、湖畔）：巨鉗蟹、溺屍鬼；沼澤夜晚：溺屍鬼。
  - 雪原：雪原巨猿；沙漠夜晚：巨蠍；高山丘陵：獅鷲、鷹身女妖；密林：梟熊；平原正午：正午魅影；平原夜晚：豺狼人、座狼。
  - 道路與城鎮周邊的夜晚：邪教徒、走私販。
  - 地下城會看地下城類型：**墓穴**有古墳屍妖、寶箱怪、邪教徒；**礦坑／洞窟**有狗頭人、寶箱怪；地下水潭房間可能有溺屍鬼。狗頭人不會出現在墓穴，古墳屍妖不會出現在礦坑。
  - 首領（萊希、遠古巨龍）**不會在路上隨機遇到**，只會出現在公會的「首領狩獵」懸賞，而且要符合地區（森林一帶的萊希、雪山一帶的巨龍）。
- 原本 152 種生物的設定、數值和出現規則都沒有更動；「和平」危險度一樣只會遇到 1～2 級的生物。

## v3.5 新功能

### 🔊 對話語音（TTS）
- 「設定 → 🔊 語音」：總開關 **「啟用語音（調用 TTS API）」預設關閉**。關閉時完全不呼叫任何語音 API，也不使用瀏覽器朗讀。
- 引擎：瀏覽器內建（免費、離線）、Azure、ElevenLabs、OpenAI。金鑰只存在**這台瀏覽器**，畫面上遮蔽顯示，**不會寫進存檔、匯出檔或角色卡**。
- 只朗讀說話角色引號「」裡的台詞；可另外開啟「旁白朗讀」。會依語氣／心情調整語調（可關閉）。
- 兩個獨立開關：「朗讀角色台詞」（預設開）、「朗讀情境旁白」（預設關）。旁白用另外的旁白聲音，預設是瀏覽器內建的中性語音（不耗雲端額度），也可改成跟角色同一個引擎。
- 遊戲會自動分辨台詞和旁白：「」『』“”裡的話是台詞，引號外的描寫、*動作*、（舞台指示）是旁白；AI 沒加引號時，會逐句判斷（第一／第二人稱、問句、語氣詞算台詞；角色名字或「她／他」當主詞的動作描寫、場景描寫算旁白）。動作／表情標籤和 OOC 永遠不念。玩家不需要打任何符號。
- 每則訊息有 🔊 重播；輸入列的 ⏹ 可停止；送出新的話會自動打斷。可設定本次遊戲的字數上限，超過後改用瀏覽器朗讀。
- 每個角色的聲音（聲音 ID、語速、音高）可在「角色 → 編輯」或語音設定頁修改，未設定時依性別、年齡給預設值。
- 說話中的角色立繪會有開口／輕微晃動效果。

### 🚪 私下空間
- 在酒館、旅店、公會、商店、神殿、宅邸、營地、地下城安全處等地點，選擇「🚪 私下空間」，進入包廂、客房、會客室等房間。
- 依世界觀換名稱與背景（例如武俠：茶樓雅間）；黑市、牢房、廢屋、洞窟深處、山寨、詛咒墓穴、下水道藏身處等危險地點有專屬的暗色房間。
- 可以和一位或多位在場角色（隊友、NPC、匯入角色）單獨談話；大立繪並排，說話的人會被強調，帶呼吸、眨眼、表情效果。
- 背景依房間、時間（日／夜）、天氣自動切換；沒有對應圖時改用夜色濾鏡、雨景疊層、地點場景圖或漸層。
- 私下談話會累積成角色的「私下回憶」，存在存檔裡，之後主線冒險時 AI 也會參考；離開時會把摘要寫進故事紀錄，時間照實經過。
- 私下空間也能用 OOC（和冒險畫面一樣：用【】、[ ]、((…)) 或「OOC:」開頭，或按 🛠️ OOC 切換）。OOC 不會被朗讀、不會觸發換裝或表情、不會寫進私下回憶或離開時的摘要。
- 可用 🎲 擲骰（可不用），服裝會被尊重（旅店客房可換睡衣），也有大膽／穩重切換，**不會有裸露**。可自訂房間。

### 👗 對話中的動作（全遊戲）
- 在冒險或私下空間都可以直接說「莉娜，拿起細劍」、「換上睡衣吧」、「把長劍收起來」。遊戲會先判斷是哪件物品／服裝、是否擁有、場合是否合適，AI 再用隱藏標記執行，畫面會顯示提示（例如「🛡️ 莉娜拿起了細劍」），立繪立刻換上。
- 場合規則可在「設定 → 遊戲 → 場合服裝規則」編輯：冒險、地下城、戰鬥可換裝備與戰鬥服；在野外換睡衣會被角色用自己的口吻拒絕；旅店客房、夜間營地可以穿睡衣；宅邸、神殿適合正式服裝。
- 物品必須真的擁有、服裝必須存在，角色可以拒絕。標記本身不會顯示在對話中。
- 拿起武器或物品時，立繪會換成對應的持握姿勢（單手、雙手、弓、手持物品），莉娜、艾薇、瑪莎、托比和玩家都有旅行與戰鬥服的姿勢；大膽模式會用大膽版姿勢。
- 物資與裝備欄改用物品圖示（依世界觀：武俠的劍是「劍」、和風的刀是「打刀」）。

## 玩法
- **示範模式**（預設，離線）：沒有固定劇情。點下方「在場」的人物搭話，或打「世界地圖」去其他地方。時間以分鐘計（一句對話約 4 分鐘、移動依距離），跨過時段時角色會照自己的作息、心情、心事自己移動，並產生「近況」事件。
- **AI 模式**：「設定 → AI 連線」選供應商、填網址、金鑰、模型，按「測試連線」，再按「儲存並使用」。AI 呼叫失敗時會自動改用示範回覆，不會中斷遊戲。

## v3.4.1 修正：世界知識書與上下文
- 修正世界知識在「系統前後、角色前、作者註記」等位置繞過總預算的問題；同一條內容只注入一次，所有位置與回應預留統一計算。
- 修整只建立送給模型的副本，**不刪除存檔或畫面上的對話**。優先保留近期對話下限，知識條目按 priority 由高到低放入；常駐也受預算限制。空間仍不足時停止送出並提示，不默默丟掉近期對話。
- 「設定 → 知識書與上下文設定」（或「記憶 → 用量與設定」）可調整，每個存檔各自保存，可重設預設值：
  - 總上下文 **12000** tokens，回應 **1000** tokens（包含在總預算內）。Token 是估算值，不是模型官方 tokenizer，請依模型容量保留餘量。
  - 知識書預算 **20%**，最多 **12** 條；預算 0% 或最多 0 條可暫停注入。
  - 掃描深度 **6** 則（預設只掃描玩家輸入），可選擇掃描 AI 回覆。每條／每本可另設更短的深度。
  - 遞迴觸發預設 **關閉**，開啟時最多 **2** 步，可調 1–5 步；仍尊重書籍與條目的遞迴排除設定。
  - 至少保留最近 **10** 則對話，近期視窗最多 **40** 則。對話長到無法同時放入系統與下限時，調高總上下文或降低下限；原始紀錄一直保留。
  - 防重複預設 **開啟**：和最近 **3** 則 AI 回覆比較，門檻 **0.90**，最多自動重試 **1** 次。接受前不顯示候選串流，避免重複內容閃現；支援溫度的設定重試時提高 0.25，未支援者不強行傳入。
  - 頻率懲罰 **0.3**、出現懲罰 **0.2**、重複懲罰 **1.1**。自動模式保守送到已知支援的供應商（LM Studio 額外使用 repeat_penalty），Anthropic 和未知模型不送。不相容可關閉；自訂 OpenAI 相容閘道可明確開啟支援。
- 「上下文檢視」列出最後一次實際請求（或尚未送出時的預覽）、系統／知識／歷史 token、啟用與略過條目理由、防重複次數，不包含 API 金鑰。縮減送出歷史時會提示，存檔紀錄不受影響。
- 若持續輸出相似內容或預算不足，停止並提示，不假裝連線失敗、不切回示範，也不生成替代劇情。真正的連線錯誤仍有示範回覆保護。重說遇到這類停止時會保留原回覆。
- 舊存檔直接沿用角色與故事；第一次使用採用以上安全預設，舊版全域固定知識書／上下文上限由本版的每存檔設定取代。

## v3.4 新功能（3.4.0）

### 世界與探索
- **四層地圖**：大陸 › 大區 › 城鎮／中型地區 › 房間／大廳。上方麵包屑可以切換層級；進入別的大區會出現轉場卡，該地區的文化與氣氛也會一起告訴 AI。
- **地下城**：廢棄礦坑、沉鐘地宮，有房間連通圖、隱藏密室和首領房。
- **點地圖移動**：點目的地會先顯示路線、所需時間和風險，確定後才出發；路上可能被遭遇打斷。

### 生物與戰鬥
- **魔物圖鑑**：預設 170 種生物（v3.5.1 新增 18 種奇幻魔物），涵蓋 8 種世界觀，每種都有 1～5 級危險度、性情、作息、成群、逃跑、察覺範圍，以及會不會主動攻擊。
- **題材規則（兩層）**：硬衝突一律擋下，例如西方地下城不會出現殭屍、武俠世界不會出現哥布林。少見的外來者要有合理的來由，由「設定 › 遊戲 › 異國元素」控制（關閉／少量／標準，預設少量）。
- **戰鬥畫面**：遭遇時切換成專屬畫面，有攻擊、技能、防禦、道具、嚇阻、交涉、馴服／招募、逃跑八個按鈕；也可以直接打字做任何事，例如「把沙子撒向野狼」。
- **魔物的數值固定**，不會成長。被**馴服**的野獸或被**招募**的人形敵人才會變成正式角色，可以升級、學技能、穿裝備，也能存成長期角色或匯出。頭目、沒有心智的不死或機械類不能收服。

### 角色、數值、擲骰
- **角色卡**：玩家、隊友、NPC、長期路人、匯入的角色都有六項屬性（名稱跟著世界觀換，例如武俠是臂力、身法、根骨……）、等級 1～20、AC、熟練技能、主動技能與法術、九個裝備欄。
- **擲骰**：🎲 按鈕或輸入 `/roll 2d6+3`、`/roll 莉娜 說服 優勢 DC15`；支援 d4～d100、優勢／劣勢、大成功／大失敗。規則參考 SRD 5.2.1（CC-BY-4.0），文字與數值為重新撰寫。
- **判定方式**（設定 › 遊戲）：
  - 並用（預設）：骰子決定結果，AI 依結果寫劇情。
  - 純擲骰：照規則判定，幾乎不呼叫 AI，沒有連網也能玩。
  - 純對話：不顯示骰子，由 AI 參考數值決定。
- **技能系統**：熟練技能（潛行、察覺、說服……）加主動技能（攻擊、治療、增益、控制、被動），各有消耗、冷卻、擲骰公式；名稱和能量跟著世界觀換（武功／內力、法術／靈力、程式／義體模組……）。

### 服裝與立繪
- **換裝**：日常、旅行、戰鬥、正式、睡衣五套，莉娜、艾薇、瑪莎、托比和玩家都有立繪。最底層一定穿著睡衣／內襯，**不會有裸露**。
- **服裝風格**（設定 › 遊戲）：穩重／大膽。大膽版只有女性角色（莉娜、艾薇、瑪莎）有，剪裁較合身、會露肩或開衩，但仍然得體；男性角色一律用一般版。
- **自訂立繪**：角色卡「立繪」分頁可以上傳多張圖並貼標籤（服裝、地點、時間天氣、情境、表情），遊戲會依目前的場景自動換上最符合的一張；會一起匯出／匯入 .json。

### 世界裡的人
- **NPC 作息**：每個人都有自己的一天，不在場就不會跟你說話；遠方發生的事會變成傳聞。
- **冒險者公會**：名稱跟著世界觀換，例如鏢局、宗門任務堂。等級 F→S，有委託板，格洛港與鐵脊鎮有分部。
- **路人**：每個地點都有臨時路人（不只公會），可以記成長期角色、匯出成角色卡 .json（chara_card_v2）、再匯入。

### 試玩回饋後補強
- **在場／同行同步修正**：
  - 遊戲只維護一份在場名單，畫面和 AI 都看這一份。
  - AI 用了不同的叫法也認得，例如「莉娜小姐」「艾薇姊姊」、簡體的「玛莎」或英文 id。
  - 同行隊友每次移動、換場景都會跟著。
  - AI 想新增一個和現有角色同名的人時，會直接擋下，不會多出重複角色。
  - 不在場的人說話會改成旁白；只有劇情寫到他走進來時，才會把他拉進場。

## v3 新功能
- **場景描繪（預設輸入模式）**：輸入框左邊可選「場景描繪（自動判斷）／對話／獨白／動作」。場景描繪會自動判斷你打的是說話、動作、內心話、場景，或是混合：「」或 “” 是說話，*…* 是動作，（…）是內心獨白，其他當成場景或動作（例如「窗外下起了雨」會改變天氣）。場景描述不會替其他角色做決定。你的訊息上會標出判斷結果（對話→莉娜／動作／獨白／場景）。每個存檔會記住上次用的模式。
- **角色反應更自然**：不是每一輪每個人都會跟你說話。每個角色依個性（莉娜話多、艾薇內斂、瑪莎很忙）、心情、好感、有沒有被搭話、正在做的事，決定要開口、只用表情動作回應、繼續忙、和別人聊，或沒注意到你。被搭話的人通常會回答，但不一定每次。還會穿插環境描寫。「設定 → 遊戲」可調整「角色主動程度」：內斂／自然（預設）／熱絡。
- **新角色要先問你**：故事想加入新角色時，會先跳出一張【系統】卡片，不算劇情，列出名字、身分、描述，並檢查是否符合世界觀。按鈕有「生成／不生成（當路人）／改名後生成／重新進行」。「設定 → 遊戲 → 新角色生成」可改成「自動」或「關閉」。這張卡片不會寫進對話紀錄或記憶。
- **世界觀設定**（「設定 → 遊戲 → 世界觀」，每個存檔各自一份）：中世紀奇幻小鎮（預設）／東方武俠江湖／仙俠修仙／日式和風（江戶）／民國（1920–30 年代）／現代都市／太空科幻／賽博龐克都市／自訂。
  - 每種世界都有自己的命名方式、用詞守則、禁用詞和貨幣，例如賽博龐克用街頭代號或混血名字、信用點、義體、企業；仙俠用道號、靈石、宗門、境界；和風用日式姓名、兩／文、藩、武士；民國用大洋、報館、英租界。
  - 示範模式的新角色名字池、環境描寫和冒險靈感也會跟著換。
  - 選「自訂…」可以自己填寫世界名稱、命名規則、用詞、禁用詞、貨幣和名字池。
  - AI 回覆出現禁用詞時會提示你，下一輪也會要求 AI 避免。
- **角色跟著存檔走**（v3.1）：匯入的角色和故事生成的角色只屬於當時的存檔，開新冒險或切換存檔時不會跑到別的世界。舊版的全域角色會在第一次開啟時移到目前的存檔。「匯出存檔」會一併帶上這個存檔的角色、立繪和角色知識書。
- **角色面板**（頂列「角色」或左側「角色」）：分成「在場／不在場」，可以請角色入場或離場、查看與編輯角色卡、匯出 .json、釘選注意、刪除故事生成的角色、更換或恢復立繪（只套用在這個存檔）。最上方「匯入角色卡」的流程是：選 .json 或 PNG 卡 → 預覽 → 可另外選立繪並自動裁出圓形頭像 → 選起始地點 → 加入。

  - 列表可以搜尋、篩選、排序、複製、刪除、批次啟用或停用，也可以用「測試觸發」貼一段對話，看哪些條目會觸發、哪些被略過以及原因。

  - 這一頁也能直接匯入 .json：知識書可以合併到目前這本或另存成新書；角色卡可以匯入為角色，或把它內附的知識書合併進來。

## v3.2 新功能與修正
- **時間變得合理**：時間改用分鐘計（頂列顯示「🕰️ 時段 HH:MM」）。一句對話約 4 分鐘、動作約 6 分鐘、四處看看約 12 分鐘；移動依距離計算。時段只有跨過界線才會換。設定 → 遊戲 →「時間流速」可選 慢／標準／快。AI 自己寫的時間跳躍會被擋下，除非你明確說「睡一覺」「等到晚上」「幾個小時後」，或故事本身清楚寫到時間流逝（例如「睡了一覺，醒來天已亮」、趕了大半天的路）；右側「世界狀態」也會顯示目前時刻。
- **建議選項符合場景**：每個地點都有自己的設施清單，例如河邊不會出現「點一杯茶」。不在場的人、你沒有的物品、這裡沒有的設施都會被濾掉並換成合適的選項（示範模式與 AI 模式都一樣）；含世界觀禁用詞的選項也會被拿掉。送給 AI 的提示裡也會列出「這裡可以做什麼、誰在場」，要求選項只寫現在做得到的事。
- **同行隊伍**：邀請角色同行後，頂列會出現「🤝 莉娜」隊伍標記（她想離開時會變成「想離開」並閃爍），右側「世界狀態」也有「同行」一欄，在場列表有「同行」標記。她會跟著你走，不會自己離開（AI 用 <move> 想直接帶走同伴會被忽略；沒問過就輸出 <party leave> 會改成先問你）。想離開時她會先問你（例如「我想去樹林那邊看看，可以先離開一下嗎？」），你可以回答「去吧，記得回來」、「留下來陪我」或「我陪妳一起去」，也可以直接打字回答。角色面板裡可以手動「邀請同行」或「請她離隊」。
- **OOC（場外指示）**：用【…】、[…]、((…)) 包起來，或以「OOC:」、「(OOC)」開頭的文字是給 AI／遊戲主持人的指示，不是故事內容：角色聽不到、時間不會走、也不會寫進故事記憶。輸入模式選單也有「🛠️ OOC（對 AI 說）」。故事和 OOC 混在一起時會自動拆開。每則 OOC 預設只用一次，按「📌 設為長期規則」就會一直有效（存在釘選事實裡）。示範模式也能處理簡單的指示，例如「把莉娜改名為莉莉」、「我的名字是阿凱」、「時間跳到晚上」。
- **重新對話（重新開始這段冒險）**：在「存檔」面板、設定的危險區域，或頂列「⋯」選單裡。會從開場重新來過，清除對話、記憶、時間、背包、隊伍和故事中生成的角色。可以選擇是否保留匯入的角色卡與知識書，也可以先匯出備份。
- **清除所有資料**：設定 → 遊戲 → 危險區域，或頂列「⋯」選單。要輸入「確認」才能執行，可勾選保留 AI 連線設定。
- **版本隔離**：第一次打開新版本時，如果瀏覽器裡還有舊版本的進度，會問你要「繼續上次的冒險」、「重新對話（同一段冒險從頭開始，保留匯入的角色卡與知識書）」、「清除所有資料（先自動匯出備份）」或「清除所有資料，不備份」。打開不同版本（包括較新版本）留下的資料時也會詢問。目前版本顯示在左側欄底部、頂列「⋯」選單和分頁標題。

- **給 AI 的新標籤**：`<party join="名字">`、`<party leave_request="名字" reason="…">`、`<party leave="名字">`（只有在你答應後才會生效）。

## v3.3.1 修正：旅行時間

## v3.3 新功能：世界地圖
- **三層地圖**（頂列「世界地圖」）：拉近看到小鎮手繪圖和鎮內地點，中間距離是手繪的區域地圖（格洛港、黃麥村、鐵脊鎮、北風關、霧林哨站、蘆湖鎮、沉鐘古塔，加上兩個無名地點），再拉遠是程式產生、可以無限延伸的大陸。按鈕：＋／−、🏘️ 小鎮、🗺️ 區域、🌍 世界、📍 我在哪、📖 圖例。手機上可以單指拖曳、雙指縮放。
- **白天／夜晚跟著遊戲時鐘**；地圖風格跟著存檔的世界觀（武俠、仙俠、賽博龐克、現代、太空、和風、民國……）。非奇幻世界的區域城鎮會換成那個世界的名字和描述，例如武俠是江湖地名，賽博龐克不會出現古代用詞。
- **迷霧**：沒去過的地方是霧。走到哪裡，那一帶就會打開。「？」是聽說過、還沒去過的地方（傳聞），去過以後才變成真正的場景。
- **出遠門**：點地圖上的地點會看到距離、路程時間和路況，按「🚶 出發」就會上路。時鐘依路程往前（例如灰石鎮到格洛港沿大路約 27 公里，走路約 5.5 小時，當天下午就到），同行的夥伴會跟著走。到了區域城鎮，選項會依當地設施調整（港口能看碼頭，不會出現「找托比」這類只有家鄉才有的選項），也一定有「前往灰石鎮」可以回家。點空白處可以往那個方向「探索」。
- **AI 會用地圖**：系統提示會附上「你附近有什麼」（describeArea），也教 AI 用兩個標籤：
  - `<newloc name="銀杉渡口" type="ferry" dir="東南" dist="9" desc="河上的老渡口">`：AI 在故事裡提到新地方時，地圖上會多一個「？」傳聞地點（每則回覆最多 2 個，違反世界觀禁用詞的會被擋掉）。
  - `<move to="格洛港">`：故事裡你們真的出發了，標記會移動、迷霧打開、時鐘依路程往前，夥伴跟著走。
- **小鎮地圖設定**：地圖右上「🧩 小鎮地圖設定」切回 v3 的小鎮地圖，可以照舊匯入自己的白天／夜晚地圖、拖曳地點位置。匯入的圖也會用在世界地圖拉近時的小鎮畫面。
- **存檔**：每個存檔各自記住地圖（迷霧、傳聞、去過的地方、你的位置）。「重新對話」會把迷霧重置。
- **手機／GitHub Pages**：寬度 820px 以下自動切成手機版：左側選單和右側場景／狀態變成抽屜（☰ 和 🖼️ 按鈕），文字放大，不會左右捲動。`web/` 資料夾可以直接放上 GitHub Pages。

### AI 地圖繪製（選用，預設關閉）
「設定 → 地圖繪製」可以讓 AI 幫走過的地方畫地圖，畫好的圖會疊在程式產生的地形上，並快取在瀏覽器裡（IndexedDB）。
- **不使用**（預設）：只用手繪區域圖和程式產生的地形。
- **模擬**：不連網，用程式畫一張測試圖，用來確認流程。
- **OpenAI 相容**：填網址（例如 `https://api.openai.com/v1`）、金鑰、模型（例如 `gpt-image-1`）。
- **A1111 / Forge（Stable Diffusion WebUI）**：填網址（例如 `http://127.0.0.1:7860`）。WebUI 要用 `--api --cors-allow-origins=*` 啟動（或填遊戲網頁的網址，例如 GitHub Pages 的 `https://你的帳號.github.io`）。
- **ComfyUI**：填網址（例如 `http://127.0.0.1:8188`），用 `python main.py --enable-cors-header "*"` 啟動。可以貼上自己用 *Save (API Format)* 匯出的 workflow JSON；內建的預設 workflow 記得改 `ckpt_name`。
- **手動匯入**：在地圖上點一個地點，按「🖼️ 匯入插圖」放自己畫的圖。
- 勾「自動繪製」會在第一次到達某個地方時自動畫，否則在地點資訊裡按「🎨 繪製這個地點」。
- 金鑰只存在你自己的瀏覽器（localStorage），不會寫進存檔或匯出檔。注意：OpenAI 相容服務從瀏覽器直接呼叫，金鑰會留在這台電腦的瀏覽器裡，只用你自己的金鑰；有些服務不允許瀏覽器直接連線（CORS），需要自架代理。
- 從 GitHub Pages（https）連本機的 A1111／ComfyUI（http）時，瀏覽器可能會擋下，這時改用本機開啟 `rpg_prototype.html`。

## 重新建置
修改 `src/` 底下的檔案後執行 `python3 build.py`，就會重新產生 `rpg_prototype.html`（地圖圖片會自動內嵌）。

## 雲端模型快速設定
「設定 → AI 連線」最上方有一排快速設定按鈕：OpenAI 均衡、Claude 均衡、Grok 均衡、Gemini 均衡、DeepSeek、豆包 均衡、OpenRouter 免費、Gemini 免費額度。按一下會建立（或切換到）一組已填好網址與模型的設定檔，只要貼上金鑰、按「測試連線」再按「儲存並使用」。選供應商後也可從「模型預設」選單換成便宜快速／均衡／最強等模型（★ 為預設），或選「自訂」自己輸入模型名稱。
- 免費金鑰：OpenRouter https://openrouter.ai/keys ・ Gemini https://aistudio.google.com/apikey （免費方案有速率限制，遇到 429 稍等即可）。
- 豆包可選中國區（火山方舟）或國際區（BytePlus）。注意：這兩個服務在金鑰錯誤時，瀏覽器只會顯示「無法連線」，請先確認金鑰、區域與模型是否已開通。

## 用 Ollama 接本機模型（3 步）
1. 安裝 Ollama 並下載模型：`ollama pull qwen2.5:7b`（中文表現較好，也可換其他模型）。
2. 允許瀏覽器呼叫：先關閉 Ollama，再用 `OLLAMA_ORIGINS=* ollama serve` 啟動（Windows：在系統環境變數加入 `OLLAMA_ORIGINS` = `*`，再重開 Ollama）。
3. 打開 `rpg_prototype.html` →「設定 → AI 連線」→ 供應商選「Ollama（本機）」→ 按「讀取模型清單」選模型 → 按「測試連線」→ 按「儲存並使用（AI 模式）」。

LM Studio：在 Developer／伺服器設定開啟 CORS，按 Start Server，供應商選「LM Studio（本機）」。

## 放上 GitHub Pages
另外附的 `web/` 資料夾已經整理好：`index.html` 就是遊戲本體（內容和 `rpg_prototype.html` 相同，只是圖片壓得比較小，手機也載得動），加上 `.nojekyll` 和 `assets/`（範例檔與地圖原圖，遊戲本身不需要它們）。把整個資料夾的內容放進一個 GitHub repo，在 Settings → Pages 選擇那個分支和資料夾就能用手機或電腦開。存檔只存在各自的瀏覽器裡，不會上傳。

## 資料存在哪裡
設定、各個存檔槽（包含每個存檔的地圖迷霧與傳聞）、知識與角色、記憶都存在你的瀏覽器（localStorage；立繪等大圖存在 IndexedDB，AI 畫的地圖插圖存在 IndexedDB 的 worldmap-art），不會上傳。API 金鑰只會送到你填的 API 位址。
